# PG Orbit for Linux

Binary releases of [PG Orbit](https://pgorbit.com), a PostgreSQL client. Source code is not published here.

## Install

Download from [Releases](https://github.com/acrogenesis/pg-orbit-releases/releases):

- **AppImage:** `chmod +x PG_Orbit-*-x86_64.AppImage && ./PG_Orbit-*-x86_64.AppImage`
- **Tarball:** extract it and run `pg-orbit-*/pg_orbit`.

Verify downloads with the matching `.sha256` file: `sha256sum -c <file>.sha256`.

## Requirements

- x86_64, glibc 2.38 or newer
- GTK 3 and libsecret, with a Secret Service provider (GNOME Keyring, KeePassXC) for saved passwords

Premium is purchased on the web from inside the app.
